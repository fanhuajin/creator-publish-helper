# Creator Publish Helper · 创作者投稿助手

Windows 键盘辅助工具：从本地文案文件读取标题、简介和标签，辅助填写 B站、抖音、小红书投稿页面。上传视频、封面设置、创作声明和最终发布由用户操作。

原快捷键版保留：`start.cmd` 启动，F5读取文案、F6按焦点填写、F9退出。新增 `bilibili_auto.cmd` 为独立B站自动化入口，可准备上传和表单，支持批量投稿。抖音、小红书的完整自动化尚未完成，继续使用原快捷键版。

## 在另一台电脑安装

安装 Python 3.10 或更高版本（带 tkinter 的 Windows 官方安装版）与 Git。在 PowerShell 中运行：

```powershell
git clone https://github.com/fanhuajin/creator-publish-helper.git
cd creator-publish-helper
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

双击 `start.cmd` 启动，运行窗口需保持打开。也可直接运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 fill_helper.py
```

不需要公司电脑的 Python 路径或 E 盘视频目录。关闭助手后可重新启动；最近一次文案选择仅保存在本机，不提交到仓库。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| F5 | 在资源管理器中单击选中文案文件，再按 F5 直接读取；成功后弹窗显示路径和标题 |
| F6 | 点击目标输入框后自动识别字段并填写；B站标题、简介、标签分别操作，抖音/小红书正文一次填写简介与关联话题 |
| F9 | 退出助手 |

F5 也支持选中一个目录，读取其中的 `发布文案.txt`。从其他窗口按 F5 会打开文件选择框。多选或文案格式错误时保持原选择。

平台依据当前浏览器窗口标题识别，字段通过 Windows UI Automation 读取当前焦点控件的输入提示、关联标签及同一行附近标签识别。不用固定坐标或字段高度猜测。无法识别、焦点变化或字段歧义时拒绝输入并弹窗提示。

B站点击标题、简介或标签输入框后分别按 F6；标签依旧追加，先手动清理旧标签。抖音、小红书点击标题框按 F6 填标题，点击正文按 F6 替换简介并追加 `#标签`，候选区域出现并稳定后按空格关联第一项，检测不确定时等待一秒。正文内已有内容与话题会被替换。

F5 选择文案，F6 自动识别并填写，F9 退出。浏览器需要向 Windows 暴露焦点输入框及其提示信息；部分浏览器版本、已填写后提示消失或平台可访问性缺失可能导致无法识别。这时不会自动降级为坐标点击或按操作顺序猜测。

对于抖音等未声明 textbox 角色的正文，读取原始可访问性树中的焦点节点；焦点为 Group/Custom 时，仅在已知编辑器类名或可写 TextPattern 证据存在时识别为正文，整页 RootWebArea 不当作正文。读取不到这些证据仍会停止。失败时 `focus_diagnostic.json` 保存本地焦点诊断，已排除 Git 提交；可能包含控件可访问名称，不上传。

话题模式需要英文输入状态，鼠标留在输入行附近。按住 Esc 可中止当前输入。执行时不要切换窗口、移动输入焦点或连续重复触发快捷键。

一次识别/填写完成前重复按 F6 会被忽略，不会排队再次输入；选择文案或错误提示期间重复的 F5/F6 也会清理。助手保持热键注册，避免 F6 传给浏览器导致焦点切换。F9 在当前处理结束后退出；需要立即中止输入时按住 Esc。此状态表示助手自己的任务是否运行，不监测你的手动打字或网页网络请求。

## 文案格式与批量操作

UTF-8 文本示例：

```text
标题：
我的视频标题

简介：
第一行简介
第二行简介

标签：
#舞蹈 #穿搭 #日常
```

三个章节必须非空，标签以空白分隔。同一文案可用于三个平台；下一条视频在资源管理器选中对应文案并按 F5，不用重启。每次填写重新读取文件，修改文案后无需重新加载。

## 使用限制

### B站批量投稿

双击 `bilibili_auto.cmd` 打开批量队列。只选择作品文件夹，不选择视频文件。
点击“批量选择作品文件夹”，选择 `dance` 等父目录，在列表中用 Ctrl/Shift 多选作品，再加入队列。也可逐个添加作品文件夹。

每个作品需要 `发布文案.txt`、`最终成片.mp4` 和 `B站4x3.png`（封面也支持 `封面.png`、`封面.jpg`）。文件夹名包含 `_跳舞` 或 `_唱歌`，分别选择舞蹈和音乐分区。
选中队列中的作品，设置北京时间的日期和小时，点击“应用到选中作品”。多选时可同时设置多个作品。取消勾选定时即立即发布；分钟保留页面值。

点击“开始批量投稿”后依次上传、填写、核对并点击“立即投稿”。部分标签未接受时继续处理。
只有确认页面显示“稿件投递成功”才从队列移除作品，随后点击“再投一个”返回上传页面，包括最后一个作品完成后。
出现错误时保留未完成作品，可在窗口继续发布剩余作品。已成功的作品不会再次发布。

运行时按 Esc 暂停，窗口显示“继续”按钮，点击恢复当前操作。暂停不计入等待超时。关闭队列停止流程。
如果 Esc 同时中断了按键助手的输入，当前作品可能报错并留在待发布列表，可继续处理剩余作品。
运行期间保持B站浏览器窗口，不要操作鼠标键盘；切换窗口会停止。

首次运行需要 uv 和 windows-mcp==0.8.5。`bilibili_auto_status.json` 记录完成作品、待发布作品和错误，不提交到Git。
批量网页流程需要实际运行验证；离线检查覆盖成功作品移除、下一条失败保留及 Esc 暂停回调。

- 快捷键助手只支持 Windows，输入框由用户手动聚焦，不自动上传或发布；独立B站脚本可自动上传并投稿。
- 全局快捷键可能和其他程序冲突，注册失败会报错。
- F5 通过 Ctrl+C 获取选中文件路径，填写使用剪贴板，都会覆盖剪贴板。
- 候选检测是局部截图变化判断，不识别话题文字，也不保证关联成功；其他浮层、屏幕位置和平台改版可能影响检测。请检查实际结果。
- 截图只在内存比较，不保存或上传；不读取浏览器密码或登录数据。
- 使用 Windows 模拟键盘事件，不等同硬件键盘，不保证平台检测结果。
- 助手与浏览器建议都以普通权限运行。

## 开发检查

```powershell
.\.venv\Scripts\python.exe test_helper.py
```

检查文案解析、平台识别、焦点字段判定及候选图像判断，不发送键鼠输入。原本地版本的填写与快速话题模式经用户试用确认；本次 F6 焦点识别尚未进行真实网页验证，三个平台的控件可访问性需在目标电脑确认。

## 抖音批量发布

双击 `douyin_auto.cmd` 打开独立的抖音队列；B站队列不受影响。批量选择作品文件夹后，逐行选择日期和小时，点击开始运行。
竖封面使用 `抖音3x4.png`，横封面使用 `B站4x3.png`，自主声明选择“内容由AI生成”，保存权限选择“不允许”。
标题、简介和话题由F6助手处理。上传期间填写，发布前等待视频与封面检查完成。
定时允许北京时间2小时后至14天内；每个作品独立设置。Esc暂停，继续恢复；成功后移除作品，从左上角“作品发布”进入下一条。
当前批量版本需要实际试跑验证；若点击发布后未确认成功，先检查作品管理，避免重复提交。

## 三端统一发布

可运行 `create_desktop_shortcut.ps1` 创建桌面“三端批量发布”快捷方式，使用内置启动图标。快捷方式通过 `multi_publish.vbs` 隐藏命令窗口启动；项目移动后重新创建快捷方式即可。

双击 `multi_publish.cmd`，批量选择作品文件夹，每条作品设置共用日期和小时。保持三个平台登录并打开各自创作中心标签页，然后点击“开始 / 继续三端发布”。程序按每条作品的B站、抖音、小红书顺序投稿，沿用各平台封面和声明设置。

每条记录保留三端状态，不自动删除。重新启动或继续运行只处理“待发布”和“失败”的平台，跳过“已完成”。Esc暂停；三端完成后由用户勾选并点击“删除选中记录”，只删除列表记录，不删除素材。修改日期和小时只影响未完成平台，不会改动已提交稿件。

如果已点击投稿但未确认成功，状态为“待核对”。先在平台查看结果，再勾选该作品点击“核对待确认结果”：已成功选择“是”，确认未提交选择“否”，尚未确认选择“取消”。统一队列保存在本地 `multi_publish_state.json`，与单平台队列独立。

离线验证：`python -B test_multi_publish.py`。覆盖已完成保留和跳过、失败续跑、提交结果不确定保护、重启恢复与状态保存。三端串联还需实际作品运行验证。
